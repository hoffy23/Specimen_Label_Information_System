The capstone project was created with three team members during my final semester of univerity. 
The project brief was to create a specimen label infomation system, with client being NSW Health.
This is prototype and has no connection to NSW Health, the design is based on their design guide. 
The techologies used is Javascipt React to create to frontend, api was created by another team member using Javascipt Node JS. 
The database MySQL using ORM sequelize to create database, Web server Express JS. 
The Nginx used for the reverse proxy.
The appilcaion can be seen by clicking on the link, which is hosted Via AWS EC2 instances.
